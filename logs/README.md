# Daily logs

One file per day: copy [`TEMPLATE.md`](TEMPLATE.md) to `day-001.md`, `day-002.md`, … and fill it in after the session. Keep it under five minutes — the tracker already records *what* you solved; the log is for *how it went*.

```bash
cp logs/TEMPLATE.md logs/day-001.md
```

If you keep your fork public, these logs double as a visible, dated record of consistent practice.
