## Features

- **Daily Plan**: 150 days of structured DSA learning
- **5 Months Coverage**: Foundations, Arrays, Linked Lists, Stacks, Queues, Trees, Graphs, DP, Greedy, Backtracking, Tries, Heaps, Advanced Topics
- **Resource Links**: Direct links to Striver, NeetCode, GeeksforGeeks, LeetCode for each topic
- **Progress Tracking**: Mark tasks complete, track percentage, localStorage persistence
- **Month Navigation**: Jump between months easily
- **Search & Filter**: Find topics quickly
- **Responsive Design**: Works on desktop, tablet, mobile
- **Dark Theme**: Easy on the eyes for long study sessions
