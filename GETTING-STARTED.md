### Step 5: Deep-Dive on Mistakes (Postmortems)
```
If you struggle with a problem:

→ Create: postmortems/problem-name.md
→ Use: Template in postmortems/README.md
→ Analyze: Why did you get it wrong?
→ Document: Correct approach and insights
```

**Example: postmortems/two-sum.md**
```markdown
# Postmortem: Two Sum (LeetCode 1)

**Difficulty**: Easy
**Date**: June 15, 2026

## What I Did Wrong
- Tried brute force O(n²) first
- Didn't think about using a hash map

## Root Cause
- Pattern misidentified
- Didn't recognize "find pair" → Hash Map

## Correct Approach
- Pattern: Hash Map for O(1) lookup
- Store each num in map with index
- Check if complement exists

## Key Insight
- Trade space for time: Use hashmap!
- This is the "Two Sum Pattern"

## Similar Problems
- Two Sum II (LeetCode 167)
- 3Sum (LeetCode 15)
```

## 💡 Pro Tips for Success

### 1. **Consistency > Intensity**
```
❌ Don't: Study 12 hours on one day
✅ Do: Study 3-4 hours every single day
```

### 2. **Understand > Memorize**
```
❌ Don't: Memorize solution and move on
✅ Do: Understand why, draw diagrams, code from memory
```

### 3. **Pattern Recognition**
```
❌ Don't: Treat each problem as unique
✅ Do: Identify patterns and connect them
```

### 4. **Write Clean Code**
```
❌ Don't: "It works, that's enough"
✅ Do: Refactor, add comments, follow conventions
```

### 5. **Explain Out Loud**
```
❌ Don't: Just code silently
✅ Do: Explain your approach before coding
```

### 6. **Track Everything**
```
❌ Don't: Rely on memory
✅ Do: Use logs/ and postmortems/ directories
```

## 🚨 Troubleshooting

### Problem: "I'm stuck on this problem"
```
1. Look at LEARNING-RESOURCES.md for that topic
2. Watch the tutorial video again
3. Check patterns.md for related patterns
4. Look at similar postmortems
5. Take a break (15 min walk)
6. Try again with fresh mind
```

### Problem: "I'm falling behind schedule"
```
1. Don't panic! Adjust, don't skip
2. Combine easy days
3. Extend timeline if needed
4. Focus on understanding, not speed
5. Review postmortems of similar problems
```

### Problem: "I'm not retaining anything"
```
1. Check if you're understanding vs memorizing
2. Explain solutions out loud
3. Code problems from memory
4. Write more detailed postmortems
5. Review patterns weekly
```

### Problem: "Dashboard isn't saving my progress"
```
1. Check browser's localStorage is enabled
2. Try clearing browser cache
3. Use same browser (localStorage is per-browser)
4. Download backup: Export JSON from dashboard
```
